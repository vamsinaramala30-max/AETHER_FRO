# AETHER Vector Illustrations

High-fidelity SVG vector illustrations designed for empty states, dashboards, feature deep-dives, and system feedback.

## Design System Color Mapping
* Dark Background: `#0B0F19`
* Glass Surface: `#1F2937`
* Primary Cyan Accent: `#06B6D4`
* Violet Accent: `#8B5CF6`
* Muted Text/Border: `#4B5563` / `#374151`
