# AETHER Typography System

This directory manages static web font imports and definitions for the AETHER design language.

## Font Stacks

* **Primary Display & Body**: Inter Variable / Inter (`'Inter', -apple-system, BlinkMacSystemFont, sans-serif`)
* **Monospace / Code / Data**: JetBrains Mono (`'JetBrains Mono', monospace`)

## Optimization
Font files should be stored in WOFF2 format for optimal compression and rendering performance across enterprise browsers.
