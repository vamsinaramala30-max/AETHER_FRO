# AETHER Lottie Animations

JSON micro-animations optimized for standard web playout engines (`@lottiefiles/react-lottie-player` or `lottie-web`).

## Conventions
* Frame Rate: 60 FPS
* Color Tokens: `#06B6D4` (Cyan Accent), `#8B5CF6` (Violet Accent), `#EF4444` (Error Red), `#10B981` (Success Green).
