# Workspace Utilities & Context Assets

Directory hosting iconography and graphics related to personal organization, day-to-day productivity tools, files, and calendar integrations.

## File Registry
- `calendar.svg`: Schedule visual interface component preview.
- `notes.svg`: Collaborative rich text document icon visual.
- `files.svg`: File manager and cloud storage folder visual.
- `productivity.svg`: Individual efficiency metric highlight visual.
- `recent.svg`: Recents / history clock indicator visual.
- `favorites.svg`: Starred/favorited elements showcase visual.
