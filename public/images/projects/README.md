# Project Management Visual Assets

This directory provides project tracking visual representations (Kanban boards, Gantt timelines, roadmaps, and milestones).

## File Registry
- `kanban.svg`: Agile column board state illustration.
- `timeline.svg`: Gantt chart task scheduling visualization.
- `roadmap.svg`: Long-term strategy curve visual.
- `tasks.svg`: Interactive task checklist visualization.
- `goals.svg`: Objective Key Results (OKR) target illustration.
- `milestones.svg`: Release marker flag illustration.
