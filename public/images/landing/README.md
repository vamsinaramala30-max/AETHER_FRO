# Landing Page Visual Assets

This directory contains key marketing and hero illustrations utilized across the public landing page of the AETHER platform.

## File Registry
- `hero-background.svg`: Main high-resolution responsive canvas gradient and grid background.
- `hero-ai.svg`: Central visual hero diagram illustrating the AETHER AI orchestration engine.
- `productivity.svg`: Feature card graphics showing velocity and productivity gains.
- `automation.svg`: Feature highlight graphic representing cross-application workflow triggers.
- `workspace.svg`: Modular interface showcase illustration.
- `knowledge.svg`: Graph view representation of connected organizational intelligence.
- `privacy.svg`: Zero-data retention and enterprise encryption badge graphic.
- `trust.svg`: Compliance and security verification badge.
- `platform.svg`: Stacked architecture view showing unified workspace infrastructure.
- `future-ai.svg`: Forward-looking visual representing autonomous agency.
