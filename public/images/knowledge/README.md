# Knowledge & Neural Indexing Assets

Assets in this folder represent knowledge graph nodes, vector database concepts, and document search UI elements.

## File Registry
- `notes.svg`: Singular knowledge note object visualization.
- `documents.svg`: Stacked enterprise document management representation.
- `search.svg`: Full-text document search visual.
- `vector-search.svg`: High-dimensional vector space cluster illustration.
- `embeddings.svg`: Matrix array / latent space embedding representation.
- `knowledge-base.svg`: Layered organizational knowledge store visual.
