# AETHER Platform Images Directory

This directory contains vector-based illustration assets organized by functional modules:

- `/landing/` - Hero backgrounds, product teasers, and value props.
- `/dashboard/` - High-level operational UI previews and analytics banners.
- `/ai/` - AI assistant, memory matrix, and conversation illustrations.
- `/workspace/` - Productivity hubs, file trees, and calendar previews.
- `/projects/` - Kanban board representations and timeline charts.
- `/knowledge/` - Knowledge graph visuals and document stores.
- `/avatars/` - System and user avatar fallbacks.
