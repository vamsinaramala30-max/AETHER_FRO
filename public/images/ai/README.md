# AI Capabilities Visual Assets

This directory contains illustrations for artificial intelligence features, neural memory, context engines, RAG pipelines, and conversational interfaces.

## File Registry
- `assistant.svg`: Icon graphic for primary conversational assistant.
- `conversation.svg`: Dual chat node graphic representing streaming dialogues.
- `memory.svg`: Tri-node network representing long-term semantic memory storage.
- `prompt-library.svg`: Bookmarks / template repository visual emblem.
- `rag.svg`: Document-to-vector indexing pipeline diagram.
- `reasoning.svg`: Multi-step decision graph illustration.
- `automation.svg`: Automated AI agent action execution visual.
