# AETHER App Brand Assets

This directory contains core brand SVG identity components for AETHER.

## Usage Guidelines
- Use `logo.svg` for header/navigation bars. Supports `currentColor` for textual elements.
- Use `logo-dark.svg` on dark backgrounds (`#020617`, `#0F172A`).
- Use `logo-light.svg` on light backgrounds (`#FFFFFF`, `#F8FAFC`).
- Use `logo-icon.svg` for square app tiles and user avatars.
